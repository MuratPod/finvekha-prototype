## 1. Принципы
1. **Плотность и порядок.** Максимум данных над сгибом: KPI-полоса на тёмно-синей шапке, плотные таблицы (строка 36 px), сетка 12 колонок с шагом 12 px.
2. **Одна главная цифра на экран** — первая ячейка KPI-полосы, 32 px; на главной это **чистый капитал** (активы − обязательства, §8.3) с датой актуальности и источниками.
3. **Факт — сплошное, прогноз — пунктир/штриховка + слово** «Прогноз / Ожидается / Оценка» (§1.4, §8.11).
4. **Каждый показатель — «на когда?» и «откуда?»** (`DataStamp`, §1.3).
5. **Смысл не держится на цвете**: знак «+/−», стрелка ▲▼, подпись (§1.5, §7.8).
6. **Нет данных — «нет данных»**, не 0. Демо — плашка «Пример»; непринятое решение — метка «Допущение».
7. **Обводки вместо теней**, без декора, без стекла и градиентов (§7.2).

## 5. Стекло из направления А — убрано
- `backdrop-filter`, полупрозрачные поверхности, радиальные подсветки фона, липкая «стеклянная» панель — **не используются**.
- Почему: в Б тёмно-синие зоны и плотные таблицы; полупрозрачность снижает и делает непредсказуемым контраст цифр, требует фолбэков (`prefers-reduced-transparency`), дорого на слабых машинах.
- Что осталось: токен `--color-glass` — алиас `--color-surface`, класс `.glass` = сплошная поверхность с обводкой (только чтобы старые образцы не ломались). `--color-bg-gradient: none`.
- Единственная «глубина» — затемнение `--color-overlay` под модалкой/шторкой (непрозрачные слои поверх).

## 6. Обязательные визуальные правила
### 6.1 Факт vs прогноз (§1.4, §2.5, §3.5, §8.11)
| Где | Факт | Прогноз |
|---|---|---|
| Линейный график | сплошная 2,5 px, `chart-1` (навы / светло-серый в тёмной), лёгкая заливка | пунктир 6/5 `forecast`, зона штриховки, граница «Сегодня» + подписи «Факт / Прогноз ›» |
| Полосы (бюджет) | сплошная заливка | штриховка 135° + легенда «Прогноз» |
| Суммы | «12 480 ₽» | «≈ 3 450 ₽» + контурный пунктирный бейдж `Прогноз`/`Ожидается` |
| События (купоны) | сплошная зелёная рамка, «✓ Получено 23.10.2026» | пунктирная рамка, тинт, «Ожидается 05.11.2026» |
| Таблицы | обычная строка | бейдж «Прогноз», фон `forecast-tint`, курсив запрещён |
Прогноз не окрашивается в positive/negative.

### 6.2 Дата и источник — компонент `DataStamp` (§1.3, §1.4, §3.9, §8.12; Q14 решён)
- Вид: caption 12 px `text-tertiary` (на шапке — `on-band-text-3`), иконка часов 12 px, формат **«Источник · дата, время зона»**.
- Источники котировок и курсов (Q14): **«Мосбиржа · 28.10.2026, 18:45 МСК»** — цены акций, облигаций, фондов; **«ЦБ РФ · курс на 28.10.2026»** — курс валют (курс ЦБ устанавливается на дату, время не пишем). Брокер: «Импорт отчёта БКС · 27.10.2026». Банк: «Т-Банк · импорт выписки · 28.10.2026, 09:15 МСК». Ручное: «Вручную · 25.10.2026».
- Время — только если источник его дал (§8.12); зона — МСК для биржевых данных, иначе часовой пояс профиля (G1).
- Параметры: `source` (Мосбиржа / ЦБ РФ / брокер / банк / вручную), `method` (импорт отчёта / импорт выписки / вручную / API — позже), `date`, `time?`, `tz?`, `rateDate?`, `priceType?` (с НКД / без НКД), `stale` (bool, по порогам A-01), `demo` (bool → рядом плашка «Пример»).
- Состояния: обычный · `stale` (иконка `warning`, текст `warning-text`, «· N дн. назад», подсказка с порогом и меткой «Допущение» — Q5) · `error` (✕ `negative`, «не удалось обновить …, показаны данные на …») · `manual` (бейдж «Вручную»).
- Размещение: под каждой ключевой суммой (в KPI-ячейке — нижняя строка), в нижней строке карточек, в таблицах — колонка «Обновлено» либо одна строка под таблицей, если источник один.
- Поповер по клику: источник, способ, дата получения, дата действия значения, курс ЦБ и его дата для пересчёта в ₽, тип цены облигации (§8.8).

### 6.2a Бейдж «Вручную» (Q4)
Серый контурный бейдж с иконкой карандаша ✎ «Вручную» (`surface-sunken` + `text-secondary`, сплошная рамка `border-control`) — отличается от «Пример» (сплошная навы-заливка), «Допущение» (фиолетовый, точечная рамка) и источника-интеграции (текстовый `DataStamp` без бейджа). Ставится на обязательства, наличные, вклады с ручными условиями, ручные оценки котировок («Ручная оценка»).

### 6.3 Устаревшие и частичные данные
Пороги — допущение (Q5), таблица — `assumptions.md` A-01: котировки Мосбиржи — > 30 мин в торговые часы / не за последнюю торговую сессию вне торгов; курс ЦБ РФ — не на текущую дату; отчёт брокера — ≥ 7 дн.; выписка банка — ≥ 7 дн.; ручные данные и обязательства — > 31 дн. Вид: иконка часов `warning` + дата текстом `warning-text` («на 21.10.2026 · 7 дн. назад»), левая полоса 3 px `warning` у карточки, баннер «Данные N источников устарели · Обновить». Сумма не прячется. Частичные — «Частично: без учёта …» у итога.

### 6.4 Плюс/минус
`▲ +12 340 ₽ · +2,1 %` / `▼ −8 120 ₽ · −0,7 %`; минус — U+2212; стрелка + `aria-label`; ноль — «0 ₽ —» нейтрально. Типы операций: ↓ доход, ↑ расход, ⇄ перевод, ↺ возврат, ⚙ корректировка + подпись.

### 6.5 Демо-данные и допущения
Плашка `ПРИМЕР` в углу каждой карточки/ячейки с демо-цифрами + глобальный баннер «Демонстрационные данные». Метка `Допущение` — рядом с элементом, чьё поведение не утверждено; по наведению/фокусу — что принято и ссылка на Q.

### 8.2 Карточка результата портфеля (`ResultCard`, Q15 решён 28.10.2026)
- **Главная цифра:** «Годовая доходность (XIRR)» — `+14,2 % годовых ▲`, KPI 24 px, знак + стрелка + подпись (не только цвет). Подзаголовок: период («за 12 мес.: 28.10.2025–28.10.2026»), «с учётом пополнений и выводов».
- **Подсказка (ⓘ у цифры):** простая доходность = прибыль / вложено: «+312 400 ₽ / 2 480 000 ₽ = +12,6 %», и пояснение, чем XIRR отличается (учитывает даты взносов).
- **База сравнения:** строка «Индекс Мосбиржи за тот же период: +9,8 %» + разница «▲ +4,4 п. п. к индексу» (± знаком и стрелкой), `DataStamp` «Мосбиржа · 28.10.2026, 18:45 МСК». Индекс — ценовой (IMOEX), а не полной доходности — пометка «Допущение» до утверждения методики.
- **Разложение:** реализованный / нереализованный результат, купоны, дивиденды, комиссии (−), налоги **удержанные брокером** (факт из отчёта). Налоговая **оценка** НДФЛ — открытый вопрос: показывается только строкой «≈ … (оценка)» с меткой «Допущение» и бейджем «Оценка», не входит в итог.
- Ссылка «Методика расчёта» (D8). Все цифры прототипа — «Пример».
